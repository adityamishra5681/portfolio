## ✨ Features

### 🎨 Design & UI
- **6 Pages:** Home, About, Skills, Projects, Education, Contact
- **Dark/Light Mode:** Toggle between themes with localStorage persistence (dark mode default)
- **Avengers Logo:** Custom SVG logo with arc reactor design
- **Particle Canvas:** Animated background with connected particles
- **Hexagonal Overlay:** Subtle geometric pattern background
- **Arc Reactor Effect:** Pulsing background animation

### 🎭 Animations
- **Hero Entrance:** Staggered slide-in animations for hero elements
- **Typewriter Effect:** Dynamic role text animation
- **3D Flip Cards:** Interactive project cards with hover flip effect
- **Scroll Reveal:** Elements fade in as you scroll
- **Hover Effects:** Shimmer, glow, and transform animations
- **Skill Bars:** Animated progress bars with smooth transitions
- **Circular Progress:** Soft skills with SVG ring animations
- **Button Ripples:** Expanding ripple effect on button hover
- **Gradient Shifts:** Animated gradient backgrounds

### 💻 Technical Features
- **Responsive Design:** Fully mobile-friendly (desktop, tablet, mobile)
- **Semantic HTML5:** Proper structure and accessibility
- **CSS Custom Properties:** Theme variables for easy customization
- **Vanilla JavaScript:** No frameworks, pure ES6+
- **Canvas API:** Particle animation system
- **IntersectionObserver API:** Efficient scroll animations
- **LocalStorage API:** Theme preference persistence

## 🚀 Getting Started

### Local Development

1. **Clone the repository**
   ```bash
   git clone https://github.com/adityamishra5681/portfolio.git
   cd portfolio
   ```

2. **Open in browser**
   ```bash
   # Simply open index.html in your browser
   # Or use a local server:
   python -m http.server 8000
   # Then visit: http://localhost:8000
   ```

### Deploy to GitHub Pages

1. **Push to GitHub**
   ```bash
   git add .
   git commit -m "Initial commit"
   git branch -M main
   git remote add origin https://github.com/adityamishra5681/portfolio.git
   git push -u origin main
   ```

2. **Enable GitHub Pages**
   - Go to repository Settings
   - Navigate to Pages section
   - Select `main` branch as source
   - Save and wait for deployment
   - Your site will be live at: `https://adityamishra5681.github.io/portfolio`
